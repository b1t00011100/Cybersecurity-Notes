# VulnHub Writeups — OSCP Preparation 🧠🔐

## 📌 Overview
This directory contains my collection of **VulnHub machine writeups**, completed as part of my hands-on preparation for penetration testing certifications and real-world VAPT roles.

The primary goal is to build a strong foundation in:
- Enumeration
- Manual exploitation
- Privilege escalation
- Attack chaining

---

## 🎯 Purpose
- Simulate real-world penetration testing scenarios  
- Develop a **methodical and structured approach** to exploitation  
- Strengthen problem-solving and critical thinking skills  
- Prepare for certifications like **OSCP / eJPT / CEH**  

---

## 🧪 Methodology
Each machine is approached like a **black box penetration test**:
- No prior knowledge of the target  
- Focus on **manual techniques over automation**  
- Minimal reliance on frameworks (e.g., Metasploit)  
- Emphasis on enumeration and logic  

---

## 🔍 Skills Practiced
- Network scanning & service enumeration  
- Web application testing (SQLi, auth bypass, etc.)  
- Credential harvesting & reuse  
- Pivoting and lateral movement  
- Linux privilege escalation  
- Misconfiguration exploitation  

---

## 📁 Structure
Each folder in this directory represents a single VulnHub machine and may include:
- Notes / writeups  
- Key commands used  
- Observations and learnings  

---

## 🧠 Key Focus
> Tools don’t hack systems — methodology does.

This repository reflects my focus on:
- Thinking like an attacker  
- Chaining vulnerabilities  
- Understanding systems, not just running tools

All machines are tested in controlled lab environments for educational purposes only.
