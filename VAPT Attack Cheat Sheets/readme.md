#  VAPT Attack Cheat Sheet

A collection of concise, structured notes on common security vulnerabilities, covering **description, exploitation techniques, impact, and remediation**.

This repository is part of my journey in **Vulnerability Assessment and Penetration Testing (VAPT)**, where I focus on understanding not just tools, but the **methodology and real-world impact of vulnerabilities**.

---

##  What’s Included

Each vulnerability is broken down into:

* **Description** – Simple explanation of the vulnerability
* **Exploitation** – How attackers actually exploit it
* **Impact** – What it can lead to in real-world scenarios
* **Remediation** – How to fix and prevent it

---

##  Topics Covered

* SQL Injection
* Cross-Site Scripting (XSS)
* Cross-Site Request Forgery (CSRF)
* Insecure Direct Object Reference (IDOR)
* File Upload Vulnerabilities
* Command Injection
* Directory Traversal
* Server-Side Request Forgery (SSRF)
* Security Misconfiguration
* Clickjacking
* Session Management Issues

*(More will be added as I continue learning and practicing.)*
