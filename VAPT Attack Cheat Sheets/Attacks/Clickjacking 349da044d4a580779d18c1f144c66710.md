# Clickjacking

- Tricks users into clicking hidden elements

### Exploitation

- Load site inside invisible iframe
- User clicks unknowningly
- This can lead to :
    - Unauthorized actions
    - Data/ Credential theft
    - Financial loss
    - Privacy Compromise
    - Malware Installations
    - Account takeover

### Remediations

- Use `X-Frame-Options`
- Use `Content Security Policy`
