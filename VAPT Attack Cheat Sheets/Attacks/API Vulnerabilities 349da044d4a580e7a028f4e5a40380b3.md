# API Vulnerabilities

- Weaknesses in API endpoints (auth, validation, rate limits)

### Exploitation

- Modify requests in Burp Suite
- Access Unauthorized data
- Bypass Authentication
- This can lead to :
    - Unauthorized Data Access & Breaches
    - Account Takeover
    - Denial of Service (DoS
    - Injection Attacks
    - Business Logic
    - Server-Side Request Forgery (SSRF)

### Remediations

- Strong Authentication
- Proper authorization
- Input validation
- Rate limiting
